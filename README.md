# Movies-Data-Analysis-SQL-Project-
A structured SQL project analyzing a dataset of 4,013 movies using MySQL Workbench. The project demonstrates practical SQL skills through queries ranging from basic counts and filters to advanced aggregations and insights.

🔧 Tools & Dataset
Database: MySQL

Tool: MySQL Workbench

Dataset: Movies Data (single table: movies)

Fields: Mname, rating, genre, year, released, score, votes, director, writer, star, country, budget, gross, company, runtime

🎯 Objectives
Apply SQL queries to extract meaningful insights from movie data

Explore ratings, genres, budgets, and box office performance

Strengthen skills in filtering, sorting, grouping, and aggregation

✅ Queries Covered
Basic: Count movies, filter by genre, ratings, release years

Intermediate: Top-rated movies, director-specific queries, budget & gross analysis, actor-specific queries

Advanced: Unique genres, average ratings, highest/lowest rated movies, genre-wise counts, director averages

📌 Key Insights
Dataset contains 4,013 movies

Only 97 movies have a rating above 8

Drama is the most common genre (809 movies)

The Shawshank Redemption is the highest-rated movie (9.3)

High-budget movies like Titanic achieved massive box office success
